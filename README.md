# Kotlin & Android Learning Projects

A collection of Android applications developed while learning Kotlin and Android development through university assignments and hands-on practice.

These projects cover fundamental Android concepts, user interface development, navigation, data storage, permissions, and Jetpack Compose.

## Projects

| Project | Description |
|---|---|
| [Calculator](https://github.com/bernayaman03/Calculator) | A basic calculator supporting arithmetic operations. |
| [BirthDay](https://github.com/bernayaman03/BirthDay) | An Android application for practicing date-related functionality. |
| [Cities](https://github.com/bernayaman03/Cities) | Displays information about cities. |
| [Intent](https://github.com/bernayaman03/Intent) | Demonstrates navigation and communication between Android activities. |
| [Permissions](https://github.com/bernayaman03/Permissions) | Demonstrates Android runtime permissions. |
| [SQLite](https://github.com/bernayaman03/SQLite) | Practices local data storage using SQLite. |
| [Jetpack Compose First Assignment](https://github.com/bernayaman03/Jetpack_Compose_Ilk_Odev) | An introductory Jetpack Compose UI project. |
| [Jetpack Compose Calculator](https://github.com/bernayaman03/Jetpack_Compose_HesapMakinesi) | A calculator with arithmetic operations and input validation. |
| [LazyColumn Country List](https://github.com/bernayaman03/LazyColumn_UlkeListesi) | Displays country information using Jetpack Compose LazyColumn. |

## Technologies & Concepts

- Kotlin
- Android SDK
- Android Studio
- XML Layouts
- Jetpack Compose
- Material Design
- Activities and Intents
- Runtime Permissions
- SQLite
- UI state management

## Purpose

These projects document my learning process in Android application development. Each repository contains an individual practice application focused on specific concepts and features.
